# Рекомендации по качеству фотографий (2022)

[English](README.md) | [Русский](README.ru.md)

Django-приложение для оценки репортажных фотографий и рекомендаций на основе анализа изображения.

## Возможности

- Регистрация пользователей и вход через Google.
- Личный кабинет с загруженными фотографиями.
- Загрузка фотографий с параметрами съемки.
- Анализ света и тени, композиции, гистограмм и контуров.
- Рекомендации по результатам анализа.

## Технологии

Python, Django, OpenCV, Matplotlib, NumPy, SQLite и django-allauth для входа через Google. Настройки созданы с помощью Django 4.0.4.

## Структура проекта

- `app/` — модели, представления, формы, миграции и анализ изображений.
- `core/` — настройки Django и маршруты.
- `templates/` — страницы аккаунта и фотографий.
- `static/` — стили и изображения.
- `env.example` — шаблон локальных настроек.

## Локальные настройки

В корне проекта скопируйте шаблон и создайте новый ключ Django:

```bash
cp env.example .env
python -c "import secrets; print(secrets.token_urlsafe(50))"
```
Запишите полученное значение в `DJANGO_SECRET_KEY` в `.env`. Для входа через Google укажите данные собственного приложения в переменных `GOOGLE_*`. Оба файла настроек читают эти значения из окружения.

После установки зависимостей проекта загрузите переменные окружения и создайте новую локальную базу из миграций:

```bash
set -a
. ./.env
set +a
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
Откройте `http://localhost:8000`. Для входа через Google настройте запись Django Sites под локальный адрес. SQLite-база создается локально; ее содержимое и `.env` исключены из Git.
